# ADR-0003: Самообновление — переименование запущенного exe

- **Статус**: принято
- **Дата**: 2026-09-10

## Контекст

Лаунчер должен обновлять сам себя. Запущенный exe нельзя перезаписать или удалить, пока процесс
жив.

## Решение

Windows разрешает **переименовать** файл запущенного процесса. `SelfUpdater.Swap` переименовывает
`<exe>` в `<exe>.old`, кладёт проверенный `<exe>.new` на исходное имя (при ошибке — откат), лаунчер
перезапускается, новый процесс удаляет `.old` через `SelfUpdater.CleanupPrevious`.

## Рассмотренные альтернативы

**bat-скрипт, ждущий выхода процесса и копирующий файл.** Классика. Отвергнуто: мигающее окно
консоли, гонки с таймаутом ожидания, антивирусы не любят exe, порождающие скрипты.

**Отдельный `updater.exe`.** Надёжно, но это второй исполняемый файл, которому самому нужно
обновление.

**Squirrel / Velopack / ClickOnce.** Готовые фреймворки. Отвергнуто: тянут свою схему установки и
публикации, а нужен один exe в папке, поставленной Inno Setup.

## Последствия

- Самообновление — это две операции переименования и перезапуск, без внешних процессов.
- Если удалить `.old` не удалось (например, антивирус держит файл), это повторится на следующем
  запуске; мешать работе он не будет.
